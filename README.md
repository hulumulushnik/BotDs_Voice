# Triarch Voice Bot

[![CI](https://github.com/hulumulushnik/BotDs_Voice/actions/workflows/ci.yml/badge.svg)](https://github.com/hulumulushnik/BotDs_Voice/actions/workflows/ci.yml)

Discord-бот для **временных голосовых комнат**. Пользователь заходит в канал-триггер
(«➕ Создать комнату») — бот создаёт ему личную голосовую комнату, переносит туда и
публикует в чате комнаты панель управления. Когда комната пустеет, она удаляется.

## Возможности

| Кнопка | Действие |
|---|---|
| ✏️ | Изменить название комнаты (без ссылок, ≤ 90 символов) |
| 🔒 | Закрыть / открыть вход для новых участников |
| 👥 | Лимит участников (0–99) |
| ⬆️ | Поднять комнату наверх категории (сразу под канал-триггер), не чаще раза в `RAISE_COOLDOWN` с |
| 🔇 | Мут / размут: если выбранный участник замучен — размут, иначе мут. Срабатывает сразу, без перезахода: бот выдаёт серверный мут и сам снимает его, когда участник уходит из комнаты |
| 🔨 | Бан / разбан: если выбранный участник забанен — разбан, иначе бан |
| 👑 | Передать владение — только тому, кто сейчас в комнате |

Все кнопки доступны владельцу комнаты. Модераторы сервера (права *Администратор*,
*Управлять каналами* или *Модерировать участников*) могут управлять любой комнатой,
и к ним нельзя применить мут или бан через панель.

**Автопередача владения.** Если владелец выходит из комнаты, она переходит к тому,
кто раньше всех зашёл из оставшихся (боты и роли «Заглушён» / «Не верифицирован»
пропускаются). Вернувшийся бывший владелец права назад не получает.

**Мут.** Бот делает две вещи: запрещает участнику говорить в этой комнате (действует и при
перезаходе) и сразу выдаёт серверный мут, чтобы микрофон выключился мгновенно. Серверный мут
бот снимает сам, как только участник переходит в любой другой канал; если тот просто
отключился от голоса — при следующем подключении. Серверные муты, выданные модераторами,
бот не трогает.

**Новая комната из своей.** Если владелец, сидя в своей комнате, заходит в канал-триггер,
старая комната передаётся следующему участнику (или удаляется, если пуста), а для него
создаётся новая комната, куда его и переносит.

Панель — два ряда (4 + 3), описание кнопок в embed — столбиком, по одной на строку:

```
┌──────┬──────┬──────┬──────┐
│  ✏️  │  🔒  │  👥  │  ⬆️  │   настройки комнаты
├──────┼──────┼──────┼──────┘
│  🔇  │  🔨  │  👑  │          участники
└──────┴──────┴──────┘
```

Раскладка задаётся одним списком `PANEL_GRID` в `cogs/triarch_voice/ui/layout.py`.

## Защита

- **Создание комнат:** у пользователя одна комната (при создании новой старая переходит
  следующему участнику или удаляется), кулдаун между созданиями, общий лимит комнат на сервер, защита от
  двойного создания при «дребезге» событий.
- **Панель:** ограничение частоты нажатий на пользователя (по умолчанию 5 за 10 с),
  повторная проверка прав в каждом модальном окне и меню выбора.
- **Переименование:** локальный лимит 2 раза за 10 минут (как у Discord), запрет ссылок и
  инвайтов, нормализация пробелов, таймаут на запрос.
- **Права:** владелец не получает прав Discord на управление каналом — всё идёт через бота,
  поэтому антиспам нельзя обойти. Серверный мут выдаёт только бот и только на время
  нахождения в комнате (см. «Мут»).
- **Роли:** «Заглушён» и «Не верифицирован» не могут создавать комнаты и не видят их;
  при выдаче «Заглушён» участник сразу отключается из комнаты.
- **Упоминания:** бот никогда не пингует `@everyone`, `@here` и роли.

Подробный разбор — в [`docs/AUDIT.md`](docs/AUDIT.md).

## CI/CD

Каждый push и Pull Request проверяется в GitHub Actions: линтер (ruff) и тесты на Python 3.10 и 3.12.
После зелёного CI на `main` бот автоматически обновляется на хостинге
[Cybrancee](https://cybrancee.com/discord-bot-hosting): ветка `production` переводится на проверенный
коммит, сервер перезапускается через API панели и сам подтягивает код из Git.
Настройка панели, секретов и откат — в [`docs/DEPLOY.md`](docs/DEPLOY.md).

## Установка

**На хостинге Cybrancee** — см. [`docs/DEPLOY.md`](docs/DEPLOY.md).

**Локально** — нужен Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # и впишите DISCORD_TOKEN
python main.py
```

### Настройка в Discord

1. **Developer Portal → Bot:** включите *Server Members Intent*.
2. **Права бота на сервере:** Просмотр каналов, Подключаться, Отправлять сообщения,
   Встраивать ссылки, **Управлять каналами**, **Управлять ролями** (нужно для overwrites),
   **Перемещать участников**, **Отключать участникам микрофон** (для мгновенного мута).
3. Создайте голосовой канал с именем из `TRIGGER_CHANNEL_NAME` — комнаты будут
   появляться в его категории.
4. Создайте текстовый канал `LOG_CHANNEL_NAME` для логов (необязательно).

## Конфигурация (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DISCORD_TOKEN` | — | Токен бота (обязательно) |
| `TRIGGER_CHANNEL_NAME` | `➕ Создать комнату` | Имя голосового канала-триггера |
| `LOG_CHANNEL_NAME` | `логи-бота` | Имя текстового канала для логов |
| `ROOM_NAME_TEMPLATE` | `🏛 \| {owner}` | Шаблон имени комнаты, `{owner}` обязателен |
| `UNVERIFIED_ROLE_NAME` | `Не верифицирован` | Роль, которой запрещены комнаты |
| `MUTED_ROLE_NAME` | `Заглушён` | Роль, которой запрещены комнаты |
| `DATA_FILE` | `data/rooms.json` | Файл состояния комнат |
| `CLEANUP_INTERVAL` | `30` | Период фоновой уборки пустых комнат, сек (≥ 5) |
| `ROOM_CREATE_COOLDOWN` | `30` | Пауза между созданиями комнаты одним пользователем, сек |
| `MAX_ROOMS_PER_GUILD` | `50` | Максимум временных комнат на сервере |
| `PANEL_RATE_ACTIONS` / `PANEL_RATE_PERIOD` | `5` / `10` | Нажатий панели за период (сек) на пользователя |
| `RENAME_RATE_ACTIONS` / `RENAME_RATE_PERIOD` | `2` / `600` | Переименований одной комнаты за период (сек) |
| `RAISE_COOLDOWN` | `60` | Пауза между подъёмами одной комнаты наверх, сек |

Некорректные значения (не число, отрицательное, шаблон без `{owner}`) останавливают
запуск с понятной ошибкой.

## Тесты

```bash
pip install -r requirements-dev.txt
ruff check . && ruff format --check .   # линтер и форматирование
pytest
```

Тесты используют заглушки discord.py и не требуют токена: антиспам, хранилище,
бизнес-логика комнат, автопередача владения, сетка и обработка нажатий панели.
