## 3. Сетка кнопок

Было: ряды по 2 / 4 / 3 / 1 кнопок с подписями разной длины — «рваная» панель.

Стало (v3): два ряда эмодзи-кнопок (4 + 3), описание в embed — столбиком,
по одной кнопке на строку:

```
[ ✏️ ] [ 🔒 ] [ 👥 ] [ ⬆️ ]   ✏️ — Изменить название
[ 🔇 ] [ 🔨 ] [ 👑 ]          🔒 — Закрыть / открыть комнату
                              👥 — Лимит участников
                              ⬆️ — Поднять комнату наверх
                              🔇 — Мут / размут участника
                              🔨 — Бан / разбан участника
                              👑 — Передать владение
```

Раскладка декларативная (`ui/layout.py → PANEL_GRID`): чтобы переставить кнопки,
достаточно изменить этот список. Старые панели перерисовываются при запуске бота.

## 4. Clean code

- Удалены BOM-символы в начале файлов, `__pycache__`, `.idea`, отладочные логи `[MUTE DEBUG]`,
  комментарии вида «# Новое поле», неиспользуемые импорты.
- Один ответственный за каждую задачу: события / логика / состояние / UI / логи.
- Пользовательские ошибки — через иерархию исключений вместо `bool` + разрозненных сообщений.
- Повторяющиеся 7 обработчиков выбора участника → таблица `MemberAction`.
- Повторяющиеся 10 декораторов кнопок → генерация из `PANEL_GRID` с проверкой,
  что у каждой кнопки есть обработчик.
- Логирование через `%`-форматирование, без f-строк в `logger.*`.
- Добавлены `requirements.txt`, `.gitignore`, `.env.example`, тесты (38 шт.), совместимость с Python 3.10+.

## 5. Что проверить вручную

Автотесты работают на заглушках discord.py, живого запуска на сервере не было
(нет токена/тестового сервера). Перед продом прогоните на тестовом сервере:

- [ ] создание комнаты, повторный заход в триггер, кулдаун;
- [ ] все 7 кнопок от владельца и от постороннего;
- [ ] мут/бан повторным выбором того же участника снимаются;
- [ ] владелец выходит — комната переходит к тому, кто зашёл раньше всех;
- [ ] в меню 👑 только участники комнаты;
- [ ] перезапуск бота при открытой комнате — кнопки должны работать;
- [ ] выдача роли «Заглушён» участнику в комнате;
- [ ] мут/размут срабатывает сразу, без перезахода;
- [ ] замученный уходит в другой канал — серверный мут снимается; отключается и заходит снова — тоже;
- [ ] серверный мут, выданный модератором вручную, бот не снимает;
- [ ] ⬆️ ставит комнату сразу под канал-триггер;
- [ ] владелец из своей комнаты заходит в триггер — создаётся новая комната, старая переходит следующему.

Комнаты, созданные **старой** версией бота, новая версия не знает (их нет в `data/rooms.json`) —
удалите их вручную один раз после обновления.

## 8. Правки по замечаниям (v4)

| # | Замечание | Что сделано |
|---|---|---|
| 1 | Мут должен выдаваться сразу, без переподключения | Переподключение и служебный канал убраны. Бот выдаёт **серверный мут** — он выключает микрофон мгновенно. Чтобы мут не «утекал» за пределы комнаты (из-за этого в v1 серверный мут был запрещён владельцам), бот запоминает, кому выдал мут, и снимает его, когда участник переходит в другой канал или при следующем подключении. Новое требование к правам бота: **Отключать участникам микрофон** (Mute Members).
Переменная `RECONNECT_CHANNEL_NAME` больше не нужна; если канал «🔇 Переподключение»
уже был создан ботом v3 — его можно удалить.
